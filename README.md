# 织光之野 · Lightweaver

纽带工作室的《织光之野》公开宣传网站。

**网站：** https://vioano.github.io/lightweaver/  
**TapTap：** https://www.taptap.cn/app/985908

纯静态 HTML / CSS / JavaScript。GitHub Pages 从 `main` 根目录发布，无构建步骤。

- 宣传美术与实际游戏画面分别标注。
- 三张 1920×1080 游戏截图来自 r70。当前20秒视频为 r75 冲浪12秒＋r74 工坊操作8秒，原生1280×720、游戏原声。两个片段经过剪接，不代表同一旅程、完整拼装成功或全流程。60 fps捕获/编码不代表已验实时60帧。旧r68短片保留用于原链接与回滚。
- 默认深色主题，手动主题选择保存在本机浏览器中。
- 使用原生视频控制，支持键盘、暂停、音量与全屏。
- 本仓库只含网站与公开营销素材，不含游戏源码和玩家存档。

本游戏内含有使用 AI 生成的游戏资产。具体使用范围和尚待核查的部分，请见 [AI 与第三方素材使用声明](https://sub.kessokuu.top/lightweaver/ai-third-party-materials-r70-20261021.html)。宣传素材的公开展示不构成素材再分发许可。

公开状态位于 `site-state.json`。已打开的页面每 8 秒检查一次同源文件；无版本变化时不修改页面。切回页面或网络恢复时立即补读。只更新状态文案、公开链接和白名单素材版本，不重新加载页面，不改变主题、滚动或键盘焦点。视频素材版本改变时保留当前播放位置、暂停状态、音量和速度。
